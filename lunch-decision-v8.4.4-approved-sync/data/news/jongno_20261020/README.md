# 종로 행사 일정·내용 수집 자료

2026-10-20(한국 시간) 공개 자료를 확인해 정리한 **실제 행사 4건·Fact 후보 8건·출처 3건**이다. 가상 샘플이 아니며 `is_demo=false`로 표시했다. 뉴스 시스템에 가져오면 모두 `candidate`로 저장된다. 일정은 변경될 수 있으므로 관리자가 원문과 대조한 뒤 검증한다.

## 파일과 가져오기

- [CSV](jongno_events_20261020.csv): Excel에서 한글을 읽을 수 있는 UTF-8 BOM 형식.
- [JSON](jongno_events_20261020.json): 같은 8건을 담은 UTF-8 객체 배열.
- 두 파일은 같은 자료이므로 **둘 중 하나만** 가져온다. 같은 주제에 재입력하면 Fact Key 중복으로 전체 요청이 거절된다.

1. 뉴스 DB 설치·업그레이드를 완료하고 Node와 FastAPI 서버를 실행한다. 스키마 오류가 있으면 [복구 안내](../../../README_NEWS_RECOVERY.md)를 먼저 따른다.
2. `/admin` → **지역 뉴스 → 새 주제**에서 실제 등록된 `서울 / 종로구`를 선택한다. 제목은 `종로 2026년 10월 행사 일정`, 분류는 문화 또는 축제로 지정한다. 시연용 체크는 해제한다.
3. **CSV·JSON 가져오기**에서 위 파일 중 하나를 선택한다. 파일 내용의 날짜는 행사일이며 `published_at`은 근거 자료의 게시 시각이다.
4. 새 주제 기준으로 **출처 3건·Fact 8건**이 저장됐는지 확인한다. 각 Fact의 **근거 연결 → 원문 대조**에서 일정·장소·프로그램과 이용조건을 확인한다.
5. 사용할 Fact만 검증 완료로 처리한다. 이후 **검증 Fact로 초안 생성 → 기사 검토·수정 → 최종 승인 → 게시**를 진행한다. 실제 AI 생성은 API 비용이 발생한다.

데이터 파일은 `district_id`를 포함하지 않는다. PC마다 지역 PK가 다르므로 업로드 전에 화면에서 종로구 주제를 선택해야 한다. 가져오기만으로 검증·AI 생성·게시·노션 전송을 실행하지 않는다. SQL 변경도 필요 없다.

`source_title`과 `source_excerpt`는 출처를 식별하고 사실을 요약한 자체 문구이며 기사 원문의 직접 인용이 아니다. 원문 제목은 링크에서 확인한다. 국내 사이트의 위 게시 시각은 한국 시간으로 해석해 `+09:00`을 붙였다. 최초 발행일을 알 수 없는 자료에 조회일을 넣어 채우지 않았다.

이 파일에는 기사 전문·사진·인터뷰를 수록하지 않았다. 공개된 일정·장소·프로그램 사실만 짧게 재서술했다. `license_note`는 이용 허가를 취득했다는 뜻이 아니며 운영 사용 전에 원문 이용조건과 출처 표시를 확인한다. 별도 기사 링크는 읽기·대조용이며 원문을 그대로 AI 입력이나 게시 본문으로 복제하지 않는다.

## 무료 확인 명령

프로젝트 루트에서 PowerShell로 실행하면 파일만 검사하며 DB·OpenAI·노션에 접속하지 않는다.

```powershell
.\.venv\Scripts\python.exe -c "from pathlib import Path; from news_service.import_data import parse_records; p=Path('data/news/jongno_20261020'); a=parse_records('csv',(p/'jongno_events_20261020.csv').read_text(encoding='utf-8-sig')); b=parse_records('json',(p/'jongno_events_20261020.json').read_text(encoding='utf-8')); assert a==b and len(a)==8; print('CSV/JSON 일치: Fact 8건')"
```

이번 검증: CSV·JSON 실제 파서 검사와 두 형식의 동등성 확인, 격리된 SQLite 테스트 DB를 이용한 FastAPI 가져오기에서 출처 3건·Fact 8건·근거 연결 8건 및 전원 `candidate` 저장 확인, 재가져오기 409와 무변경 확인, 기존 가져오기 테스트 11개 통과. 운영 DB·실제 MySQL·브라우저·OpenAI·노션 호출은 이번 데이터 추가 작업에서 실행하지 않았다.
