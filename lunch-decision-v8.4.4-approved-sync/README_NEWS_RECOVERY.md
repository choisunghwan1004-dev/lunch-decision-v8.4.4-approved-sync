화면에 **뉴스 설치 후 Node와 FastAPI를 다시 시작하세요** 또는 **뉴스 연결 설정이 준비되지 않았습니다**가 표시되면, 뉴스 API 연결 설정부터 준비해야 합니다. 이때 목록 조회가 실패하므로 시군구 옵션과 기존 주제가 표시되지 않습니다.

## 현재 PC에서 복구하기

1. 최신 ZIP을 별도 폴더에 압축 해제합니다. `package.json`과 `18_뉴스_연결복구.bat`이 함께 있는 안쪽 폴더를 엽니다.
2. 기존 프로젝트의 `.env`를 새 프로젝트 폴더로 복사합니다. MySQL 비밀번호·OpenAI 키·노션 설정이 들어 있는 본인의 파일을 사용하세요.
3. 실행 중인 Node·FastAPI 창에서 각각 **Ctrl+C**를 눌러 종료합니다.
4. **`18_뉴스_연결복구.bat`**을 실행합니다. 필요한 Python 환경·라이브러리·뉴스 연결 설정·뉴스 테이블을 준비하고 `Regions`, `Topics` 개수를 표시합니다. OpenAI 유료 호출은 없습니다.
5. “연결 복구 준비 완료”가 나오면 **`09_뉴스_서버시작.bat`**을 실행합니다. 서버 창 2개를 유지합니다.
6. `http://127.0.0.1:3100/admin`에서 **Ctrl+F5**로 새로고침한 뒤 다시 로그인합니다.
7. **지역 뉴스 → 연결 다시 확인**을 누릅니다. “뉴스 서버 연결됨”과 시군구·주제 개수가 표시되면 작업할 수 있습니다.

`py` 실행기가 없어도 `python` 명령이 동작하면 준비할 수 있습니다. 둘 다 없다면 Python 3.11 이상을 설치하고 PowerShell을 다시 여세요. 이 프로젝트는 Python 3.12에서 검증했습니다.

## 시군구를 선택하고 주제를 만드는 순서

1. **새 주제**를 누릅니다.
2. 지역 선택에서 `서울 / 종로구`, `도쿄도 / 신주쿠구` 같은 등록된 시군구를 고릅니다.
3. **주제 칸에는 제목을 직접 입력**합니다. 예: `종로 지역 관광지 소식`.
4. 분류를 선택하고 **주제 저장**을 누릅니다.
5. 창이 닫히고 저장한 주제가 자동 선택됩니다. 바깥의 **뉴스 주제** 목록에서 다른 저장 주제로 전환할 수도 있습니다.

등록된 주제가 0개일 때는 선택할 기존 주제가 없으므로 먼저 새 주제를 저장하세요. 시군구가 0개라면 **지역 관리**에서 지역을 등록하세요. 화면 시험용 가상 지역이 필요할 때만 `npm run seed:demo`로 한국·일본 시연 자료를 넣을 수 있습니다.

## 멈춘 단계별 확인

| 표시·상태 | 확인 방법 |
|---|---|
| 뉴스 연결 설정 미준비 | 18번 복구 후 두 서버를 모두 종료·재시작 |
| 연결 설정이 다름 | 이전 Node 또는 FastAPI가 남아 있는지 확인하고 모두 재시작 |
| FastAPI(8001)에 연결 불가 | Python 서버 창의 오류 확인; 09번으로 두 서버 실행 |
| DB 로그인 실패 | 프로젝트 루트 `.env`의 `DB_USER`, `DB_PASSWORD` 확인 |
| 뉴스 테이블 설치 필요 | 18번 실행; 지원되는 구형 스키마는 백업 후 `18_뉴스_연결복구.bat --upgrade-existing` |
| 등록된 시군구 없음 | 지역 관리에서 등록 후 연결 다시 확인 |
| 등록된 주제 없음 | 새 주제에서 시군구·제목을 입력하고 저장 |
| 포트 사용 중 | 기존 서버 창에서 Ctrl+C를 누른 뒤 다시 실행; 다른 프로그램은 임의로 종료하지 않음 |

## PowerShell로 복구하기

아래 명령은 `package.json`이 있는 프로젝트 폴더에서 한 줄씩 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r news_service\requirements.txt
.\.venv\Scripts\python.exe -m news_service.setup --init-env
```

이미 가상환경이 있으면 첫 줄은 생략할 수 있습니다. 연결 설정만 준비할 때는 DB 연결이 필요 없는 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m news_service.setup --init-env-only
```

이 명령 이후 기존 서버 창을 종료하고 09번으로 다시 시작해야 두 프로세스가 같은 설정을 읽습니다. 설정 파일이나 키 원문을 채팅·GitHub에 올리지 마세요.

## 이번 수정과 확인 범위

- 연결이 준비되기 전에는 새 주제·주제 선택을 비활성화하고 복구 방법을 표시합니다.
- 오류·시군구 0개·주제 0개를 구분하고 재확인 버튼으로 목록을 다시 읽습니다.
- 주제 저장 후 자동 선택, 한국·일본 주제 전환, 이전 주제의 느린 응답이 현재 화면에 섞이지 않는 처리를 보강했습니다.
- 유효한 연결 토큰을 반복 설치 때 재발급하지 않도록 따옴표·공백·export 형식을 처리합니다.
- 09번은 서버 시작 전에 연결 설정만 준비합니다. 18번은 실제 테이블 설치까지 수행합니다.
- Python 준비 파일은 `python`, `py` 순서로 실행 가능한 설치를 찾습니다.

검증 결과는 [NEWS_TEST_REPORT.md](NEWS_TEST_REPORT.md)를 보세요. 실제 Windows 배치 실행과 본인 PC 설정은 해당 환경에서 확인해야 합니다.
