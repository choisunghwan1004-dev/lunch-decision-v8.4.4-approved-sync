# 변경 이력

이 문서에는 변경 목적과 실제 검증 결과를 기록한다. 상세 실행 방법은 [README](README.md), 코딩 작업 절차는 [AGENTS.md](AGENTS.md)를 따른다.

## 2026-10-20

### README 실행 화면 GIF 영역과 Windows 녹화 안내

- 예시와 같은 접기·펼치기 방식으로 점심 추천·여행 일정·지역 뉴스의 시연 영역을 추가했다.
- 실제 녹화 파일은 아직 없어 각 영역을 녹화·업로드 대기로 표시했다. 미등록 GIF의 이미지 태그는 주석으로 두었다.
- `docs/SCREEN_RECORDING.md`에 ScreenToGif 준비, 화면 녹화, GIF 저장, 저장소 업로드, README 활성화, 재생 확인 방법을 추가했다. 저장소 업로드와 댓글 첨부의 용량 제한을 구분했다.
- 검증: 기존 README·변경 이력 보존, 새 상대 링크·앵커·접기 태그·코드 블록·이미지 대기 처리, 변경 파일 차이·공백을 검사했다. 공식 배포·사용법과 GitHub 문서를 확인했다.
- 미실행: 실제 Windows 녹화와 GIF 재생 검증. 애플리케이션 변경이 없어 앱·DB·외부 API 테스트는 다시 실행하지 않았다.

### 문서·검증·커밋 처리 절차 저장

- 시스템을 수정할 때 README와 관련 상세 문서 갱신, 변경 이력 기록, 필요한 테스트, GitHub 커밋을 같은 작업에서 처리하도록 `AGENTS.md`에 기록했다.
- SQL·환경설정·실행 방법 변경 시 함께 갱신할 문서와 검증 기준을 정리했다. 커밋 전 대상 파일·비밀정보 확인과 원격 변경 보존 절차를 포함했다.
- README에 처리 절차와 관련 문서 링크를 추가했다. 이 절차는 코딩 작업에 적용되며 사용자 PC의 파일 감시나 별도 자동 커밋 서버를 설치하지 않는다.
- 검증: 변경한 Markdown의 로컬 링크, 문서 간 안내, `git diff --check` 확인. 문서만 변경해 애플리케이션 테스트와 외부 API 호출은 다시 실행하지 않았다.
