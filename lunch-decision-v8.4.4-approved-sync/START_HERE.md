# 지역 뉴스 실행 순서

기존 점심·여행 화면과 함께 동작하는 뉴스 추가분입니다. 먼저 `package.json`이 있는 이 폴더에서 작업하세요. Node.js와 Python이 필요합니다.

1. **무료로 코드 확인**: `10_뉴스_무료테스트.bat`을 더블클릭합니다. MySQL과 OpenAI 키 없이 검사하며 `test-results/checks-offline.json`의 `passed: true`를 확인합니다.
2. **SQL 준비**: MySQL을 실행하고 루트 `.env`의 DB·관리자 설정을 채웁니다. [README 7절](README.md#7-sql-파일-처리-방법)의 신규/기존 DB 절차를 구분해 실행합니다. 기존 설치의 `08_뉴스_설치.bat`은 옛 DB 백업이 필요할 수 있습니다.
3. **실제 DB 검사**: `11_뉴스_MySQL테스트.bat`을 실행합니다. 테스트 계정은 별도 테스트 DB를 생성·삭제할 권한이 있어야 합니다.
4. **서버 시작**: `09_뉴스_서버시작.bat`으로 FastAPI와 Node 서버를 실행합니다. 관리자 주소는 `http://127.0.0.1:3100/admin`입니다.
5. **파일 수집 확인**: 지역 뉴스에서 시연용 주제를 만들고 `CSV·JSON 가져오기`로 `examples/news_demo.csv` 또는 `.json`을 선택합니다. Fact 3건이 검증 대기로 들어오고 같은 파일 재수집은 중복으로 차단되는지 확인합니다.
6. **화면 자동 검사**: `12_뉴스_브라우저테스트.bat`으로 등록·검토·승인·게시·일본·모바일·파일 가져오기를 별도 DB에서 확인합니다.
7. **운영 초안 생성**: 본인의 OpenAI 키와 `gpt-6-luna` 권한을 준비합니다. 실제 원자료를 등록·검증한 뒤 초안을 생성하고 사람이 문장별 대조·최종 승인·게시를 수행합니다. API 비용이 발생할 수 있습니다.

무료 검사의 AI 응답은 테스트 대역입니다. 실제 모델 호출, Notion 등록, 오전 9시 예약을 대신 실행하지 않습니다. 시연 자료는 운영 승인·게시할 수 없습니다. Windows 배치 자체는 이번 Linux 환경에서 직접 실행하지 않았고, 내부 실행기와 실제 MySQL·브라우저 명령을 검증했습니다.

첨부 평가 양식에 맞춘 답안은 [문서](docs/ASSESSMENT.md), 코드·DB 세부 설명은 [README](README.md), 실제 검사 범위는 [검증 기록](NEWS_TEST_REPORT.md)을 확인하세요.
