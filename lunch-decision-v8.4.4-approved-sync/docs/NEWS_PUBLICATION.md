# 저장한 뉴스가 메인에 보이지 않을 때

**Fact 검증 저장 → 기사 초안 저장 → 최종 승인 → 승인본 게시**는 별도 단계다. 메인은 승인 후 게시된 운영 기사만 표시한다. 출처·Fact 또는 미게시 초안은 저장되어 있어도 공개 목록에 나오지 않는다.

2026-10-20 보고된 화면은 “아직 이 지역에 게시된 소식이 없습니다”라는 빈 목록 안내였다. 첨부 화면만으로 사용자 DB의 저장 실패 여부를 확정할 수는 없다. 코드에서는 **게시 전에 열어 둔 메인이 관리자 게시 후 자동 재조회하지 않는 문제**를 확인해 수정했다. DB 삭제·초기화나 미승인 기사 공개로 해결하지 않는다.

## 업데이트 후 확인 순서

1. 최신 코드를 내려받고 기존 서버 창을 종료한 뒤 `09_뉴스_서버시작.bat`으로 다시 시작한다. 관리자·사용자 페이지에서 **Ctrl+F5**를 누른다. 이번 변경에 추가 SQL은 필요 없다.
2. 관리자 `/admin` → **지역 뉴스**에서 해당 시군구·주제를 선택하고 **메인 노출 상태**를 확인한다.
3. 아래 표에 따라 현재 저장 단계에서 이어서 진행한다. 다시 입력하거나 DB를 초기화하지 않는다.
4. 게시 후 **사용자 화면의 전체 지역 소식 확인** 링크를 열거나, 메인의 **전체 지역 → 새로고침**을 누른다. 메인 상태 안내에 현재 조회 지역도 표시한다.

| 관리자 상태 | 의미 | 다음 동작 |
| --- | --- | --- |
| 출처·Fact 수가 있음 / 기사 0건 | 원자료·검증 자료만 저장됨 | 검증된 Fact로 초안 생성. 실제 OpenAI 호출에는 키·모델 권한·비용 확인 필요. |
| 기사 수가 있음 / 승인·게시 0건 | 초안 또는 검토·수정 상태 | 기사 검토·수정에서 제목·문장 근거 대조와 최종 검토 |
| 승인 1건 / 게시 0건 | 최종 승인은 저장됐지만 미게시 | 승인된 기사를 열어 **승인본 게시**. 이제 최종 승인 직후 창을 유지해 게시 버튼을 표시함. |
| 게시 1건 | 게시 상태가 DB에 저장됨 | 같은 시군구 또는 전체 지역에서 새로고침. 점심 지역과 여행 지역은 서로 다를 수 있음. |
| 시연용 주제·출처 | 운영 게시 제한 | 실제 근거를 사용한 운영 주제에서 제작. 시연 표시만 임의로 바꿔 공개하지 않음. |
| 근거 변경·게시 중단·수정 요청 | 공개 조건이 해제됨 | 현재 근거로 새 수정본·문장 검토·승인·게시 절차 진행 |

## 이번 수정

- 관리자에서 출처·Fact·검증 수와 기사·승인·게시 수, 다음 작업을 안내한다. 이를 통해 “저장되지 않음”과 “저장됐으나 미게시”를 구별한다.
- 최종 승인 후 기사 창을 유지하고 **승인본 게시**를 안내한다. 승인과 게시를 합치지 않는다.
- 관리자 게시·중단 후 같은 브라우저의 다른 탭에 시각 알림을 보내 메인을 다시 조회한다. 원문·초안·토큰을 브라우저 저장소로 전달하지 않는다.
- 메인으로 화면을 전환할 때도 조회하고, **새로고침** 버튼을 제공한다. 다른 브라우저나 다른 기기에서 게시했다면 메인의 새로고침 또는 화면 복귀로 확인한다.
- **점심 지역·여행 지역·전체 지역**을 선택할 수 있고 빈 목록에도 현재 조회 지역을 표시한다. 전체 지역 역시 서버의 승인·게시·근거 검사를 통과한 기사만 제공한다.

게시 1건인데 전체 지역에서도 보이지 않으면 뉴스 연결 상태·게시 중단 여부·현재 근거와 승인 내용의 일치 여부를 확인한다. 실제 저장 자료를 보지 않은 상태에서 손실·오류 원인을 단정하지 않는다. [뉴스 연결 복구](../README_NEWS_RECOVERY.md), [기능·DB 설계](../README_NEWS_V8.5.2.md)를 함께 참고한다.

## 검증 범위

격리 MySQL의 실제 Node/FastAPI 화면에서 메인을 먼저 열고, 모의 AI 응답으로 만든 테스트 기사를 검토·승인·게시해 열린 메인의 자동 반영을 확인한다. 승인만 했을 때 미노출, 다른 지역 필터, 전체 지역, 원자료 상세, 게시 중단 후 목록 제거도 확인한다. 실제 OpenAI 호출·사용자 운영 DB 게시·Windows BAT 직접 실행과 구별한다. [실행 GIF](../README.md#demo)의 게시 시연에도 모의 응답 표시를 남긴다.
