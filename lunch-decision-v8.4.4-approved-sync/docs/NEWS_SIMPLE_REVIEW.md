기능·화면·DB·수집·환경의 통합 기재와 실제 검증 결과는 [추가·변경 보고서](NEWS_CHANGE_2026-10-20.md)를 참고하세요.

관리자 `/admin` → **지역 뉴스 → 주제 선택 → 원문 비교·검증**에서 사용한다.

1. 왼쪽의 **원문 근거**와 오른쪽의 **기사 제목·본문**을 비교한다. 필요한 경우 원문 링크를 열어 날짜·수치·지역·출처 이용 조건을 확인한다.
2. **원문과 기사 내용을 대조했습니다** 확인 한 개를 체크한다.
3. **검증 완료·저장**을 누른다. 검토 메모는 비워도 된다.
4. 메인의 **지역 소식**에 기사와 원문 출처가 표시된다. 메인의 선택 시군구와 주제 시군구가 같아야 표시된다. 관리자 **이 지역 소식 확인** 링크는 해당 시군구를 선택해 메인을 연다.

개별 문장마다 체크·의견을 입력하거나 최종 확인 4개·승인본 게시를 따로 누르지 않는다. Fact 목록의 **상태 변경** 항목도 제거했다. 사실 내용 수정·근거 연결·원문 대조·삭제는 유지한다.

## 승인 저장 오류의 원인과 수정

첨부 화면의 `String should have at least 3 characters`는 예전 필수 검토 의견이 비어 발생한 입력 오류였다. `Input should be True` 4개는 예전 확인 체크 4개가 비어 발생했다. 두 경우 DB 쓰기 전에 요청이 거절됐다.

기본 화면은 새 `POST /drafts/{id}/verify-and-save`를 사용한다. 입력은 **원문 대조 확인 1개, 선택 메모, 열어 본 기사 해시**다. 메모 없음·짧은 메모를 허용한다. 확인 없이 누르면 “원문 대조 확인을 체크하세요”라고 안내한다. Fact 원문 대조의 메모와 기사 수정 메모도 선택으로 바꿨다.

## 어떤 상태를 저장하는가

사람이 기사 전체를 원문과 대조했다고 확인한 기록으로 문장 근거 대조, 승인 이력, 공개 상태를 **같은 MySQL 트랜잭션**에 저장한다. 중간에 실패하면 모두 취소해 승인만 남거나 일부만 저장되는 문제를 막는다. 같은 기사를 반복 저장해도 현재 공개본·근거가 같으면 중복 공개·검토 이력을 만들지 않는다.

기존 문장별 Fact 연결·원자료 스냅샷·검토자·시각·승인 이력은 유지한다. 기존 상세 검토·승인·게시 API도 이전 연결과 테스트 호환을 위해 유지하지만 기본 화면에서는 여러 버튼을 노출하지 않는다. 사람이 확인하지 않은 초안이나 시연 자료를 자동 공개하지 않는다. 원문·Fact가 변경됐거나 불일치로 표시된 내용은 수정본으로 다시 검증해야 한다.

**Fact만 검증해도 메인에 표시된다.** 출처·근거를 연결한 뒤 Fact의 원문 대조 → Fact 검증 완료를 누르면 운영용 주제의 내용·출처가 **원문 검증 소식**으로 표시된다. AI 기사 생성은 선택이다. 초안을 만든 상태에서는 검증된 Fact 소식만 보이고, 위 기사 검증·저장을 마치면 같은 주제의 **검증 기사** 카드로 교체된다. 실제 AI 생성에는 본인의 OpenAI 키·모델 권한이 필요하며 비용이 발생한다. 이 변경은 URL 자동 수집이나 AI의 진위 판정을 추가하지 않는다.

## 메인과 공개 중단

메인은 **지역 소식** 제목과 새로고침만 제공한다. 점심·여행·전체 지역 전환은 제거했고, 최근 검증 Fact 소식·기사 최대 30건을 표시한다. Fact 검증·수정·삭제·기사 저장·공개 중단 알림과 화면 복귀 때 다시 조회하며, 보이는 화면은 30초마다 갱신한다. 기사를 열면 본문·지역·원문 출처를 확인할 수 있다.

공개된 기사를 관리자에서 열어 **공개 중단**을 누르면 지역 소식에서 빠지고 Fact 카드로 자동 재등장하지 않는다. 기사 게시 이력이 있는 주제는 Fact를 다시 검증해도 기사 경로로 관리한다. 다시 공개하려면 원문을 대조하고 검증 완료·저장을 누른다. 수정하려면 **내용 수정·검증 기록**을 펼쳐 기사 내용 수정을 선택한다. 기존 원문과 이전 수정본은 덮어쓰지 않는다.

## 적용 방법

최신 코드를 적용하고 기존 Node·FastAPI 서버 창을 종료한 뒤 **09_뉴스_서버시작.bat**으로 다시 시작한다. 관리자·사용자 화면 모두 **Ctrl+F5**로 새 스크립트를 읽는다. **SQL 추가 적용이나 DB 초기화는 필요 없다.** 기존 자료는 보존한다. 첨부 화면의 **점심과 여행, 지역 소식 / 점심 지역·여행 지역**은 이전 UI다. [내려받은 파일·실제 제공되는 화면을 구별하는 PowerShell 확인](NEWS_PUBLICATION.md#최신-화면을-실행하고-있는지-확인)을 따른다.

Fact 공개·제외·기사 교체·중단 검사는 [tests/news/test_public_facts.py](../tests/news/test_public_facts.py)에 있다. 기사 간편 저장 테스트는 [tests/news/test_simple_review.py](../tests/news/test_simple_review.py)와 [브라우저 통합 검사](../tests/news/browser_smoke.py)에 있다. 빈 메모, 확인 누락, 중복 저장, 근거 변경·시연 자료 차단, 실패 시 전체 취소, 기존 승인본 호환, 저장 후 메인 반영을 검증한다. 공개 GIF의 AI 응답은 테스트 대역이며 운영 기사 게시나 실제 유료 OpenAI 호출과 구별한다.
