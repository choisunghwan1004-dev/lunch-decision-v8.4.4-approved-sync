# 지역 뉴스 출처 등록 — 실제 입력 예시

관리자 `/admin` → **지역 뉴스 → 시군구·주제 선택 → 출처 등록**에서 입력한다. 이 화면은 원자료와 링크를 저장한다. **URL만 입력해도 기사 본문을 가져오는 기능은 없다.** 필요한 내용은 원문을 직접 읽고 입력하거나, 준비된 [종로 CSV/JSON](../data/news/jongno_20261020/README.md)을 가져온다.

## 종로 가족행사 자료 한 건을 직접 등록하기

2026-10-20에 [자치행정신문 원문](https://www.ddmnews.co.kr/news/796125)과 [해당 사이트 이용약관](https://www.ddmnews.co.kr/shop_add_page/index.htm?page_code=page02)을 직접 열어 확인한 예시다. 행사 일정은 변경될 수 있으므로 실제 기사 작성 전에 다시 확인한다.

| 화면 입력 항목 | 입력 예시·판단 기준 |
| --- | --- |
| 자료 종류 | **기타** (`other`). 언론사 기사이므로 공식 기관으로 분류하지 않는다. 파일로 가져왔다고 원자료 종류가 자동으로 CSV가 되는 것은 아니다. |
| 발행 기관 | `자치행정신문` |
| 자료 제목 | `종로 가족행사 일정·프로그램 안내(요약 제목)` — 원문을 찾을 수 있도록 붙인 자체 식별 제목 |
| 공식 원문 URL (HTTPS) | `https://www.ddmnews.co.kr/news/796125` — 이 필드는 근거를 확인할 원문 주소이며 기관의 공식성 인증은 아니다. |
| 자료 공개 시점 (UTC) | **2026-10-13 23:49**. 원문 표시 `2026-10-14 08:49`를 한국 시간으로 해석해 9시간 뺀 값이다. |
| 원자료의 관련 구절 | 직접 인용: **“마로니에공원에서 오전 11 시부터 오후 4 시까지 진행한다.”** |
| 이용 조건·인용 범위 | `2026-10-20 확인. 기사 하단 저작권 표시와 이용약관 제22조 확인. 영리 이용 시 사전 승낙 제한이 있어 허가 확보 전 전문·사진 재게시 제외. 일정 확인용 최소 구절과 원문 링크만 기록.` |

위 구절은 **행사 시간**의 근거다. 날짜·장소·프로그램을 검증할 때는 그 정보를 담은 원문 위치도 별도로 확인한다. 기사 전체를 붙여 넣거나 확인하지 않은 이용 허가를 적지 않는다. 요약해서 입력했다면 `요약:`이라고 명시하고 원문 직접 인용과 구별한다.

현재 폼은 시간대 선택 없이 **UTC**로 저장한다. 한국 시간 `2026-10-14 08:49`를 그대로 입력하면 9시간 차이가 생긴다. CSV/JSON의 `published_at`은 `2026-10-14T08:49:00+09:00`처럼 시간대를 포함할 수 있으며 가져오기에서 UTC로 정규화된다. 공개 시점은 **자료 발행일**이며 행사일·오늘 날짜가 아니다.

## 등록 후의 흐름

1. **출처 저장**으로 원자료 한 건을 저장한다. 이 단계만으로 Fact나 기사가 만들어지지 않는다.
2. **Fact 등록**에서 일정·내용 등을 짧게 나누어 입력한다.
3. **근거 연결**에서 해당 출처와 본문 위치·대조 의견을 연결한다.
4. **원문 대조**에서 날짜·수치·지역·표현·이용 조건을 직접 확인하고 **Fact 검증 완료**로 처리한다.
5. 검증된 Fact로 초안을 만들고 문장별 대조·수정·최종 승인 후 게시한다.

CSV/JSON 가져오기는 1~3의 출처·Fact·연결 저장을 묶어 처리한다. **새 종로 주제에서 출처 3건·Fact 후보 8건**을 저장하며 4번의 사람 검증은 따로 필요하다. 직접 등록과 같은 자료의 CSV 가져오기를 중복 실행하지 않는다.
